# GVK ToolCore Tools

The ship tools of the **GV: Deserts of Kharak (GVK)** server, built on ToolCore: the welders, grinders and drills that replace the vanilla ones, the Advanced Ship Drill, and the **Heavy Salvage Beam Turret**, a salvage turret that shuts itself off if a player armors it into a bunker.

## Philosophy
- **Rules live in the block.** The turret checks its own surroundings and explains what to fix, so no admin has to referee a build.
- **Tools count against the grid's limits.** The welders, grinders and drills are limited by the Ship Core Framework like the vanilla tools they replace.
- **Replace, don't stack.** The vanilla ship tools are hidden by ModAdjuster rather than left beside the GVK ones.

## Requirements
- The ToolCore framework mod, [3040438530](https://steamcommunity.com/sharedfiles/filedetails/?id=3040438530).
- The Ship Core Framework pack ([GVK-ShipCoreFramework](https://github.com/GV-Server-Mods/GVK-ShipCoreFramework)), which counts the tools in its limits.
- Loaded with the rest of the server mods: [Steam collection](https://steamcommunity.com/sharedfiles/filedetails/?id=2650582206).

## The salvage turret in brief
The turret checks two stacked zones around it: a workspace that must stay mostly clear and a sky zone above it that must stay completely clear. A violation shuts it down, says which layer is wrong in its control panel, and can draw a wireframe of the legal space. NPC grids are exempt. The whole design, including the ToolCore workarounds and why the beam is a line and not a sphere, is in [Docs/design/salvage-beam-turret.md](Docs/design/salvage-beam-turret.md).

## For other modders
Worth reading in the design doc:
- **Rules enforced by the block itself** with event-driven checks that cost nothing while a grid is unchanged.
- **Why a line beam beats a working sphere** for salvaging: it can't reach through armor.
- **Two ToolCore quirks** and their workarounds (the missing beam state, and the model offset after resizing a block).

## Building
An MDK2 mod project. `dotnet build -c Release`, or Ctrl+Shift+B in VS Code, packs and deploys it to your local Mods folder. Check the deployed copy has your change before testing in game.
